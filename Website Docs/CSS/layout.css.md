# layout.css

**Role**: layout containers and spacing utilities. Tiny (21 lines).

- `main { width: 100% }`
- `.container` — `--max-width` (1400 px) centered column with `--space-md` side padding. Rarely used; most pages set their own max-width inline or per-component.
- Utilities: `.text-center`, `.mt-sm/md/lg`, `.mb-sm/md/lg` (margins from the [[base.css]] spacing scale). `.mt-lg`/`.mt-md` appear in the detail templates around back-buttons.
