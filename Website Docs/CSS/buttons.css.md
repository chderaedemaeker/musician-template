# buttons.css

**Role**: the button family. (31 lines)

- `.btn` — the standard pill: off-white background, 1 px `--warm-grey` border, `--radius` corners, sans font. Hover inverts to near-black background / white text. Used everywhere (biography link, "All Concerts", tickets, back-to-overview…).
- `.btn-primary` — pre-inverted (near-black bg); rarely used.
- `.btn-sm` — tighter padding; used for back-buttons and the newsletter ↗ submit on [[Contact Page]].

Note: font-size uses the legacy alias `--font-size-sans` from [[base.css]].
