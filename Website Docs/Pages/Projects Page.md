# Projects Page

**Source**: `_input/{lang}/projects.html` · **URL**: `/{lang}/projects/` · **Layout**: `default.html`

A minimal text list (`.text-list`, [[cards.css]]) of the per-language `projects_{lang}` collection (ensembles like Trio Gilu, Duo Altiler, ERMA Ensemble…), newest first. Each row: title, collaborators, and a ↗ arrow linking to the [[Project Detail]] page.

## Notes

- **Not linked from the navigation** — `_data/navigation.js` only has About / Concerts / Highlights / Contact. Visitors reach projects through the grid at the bottom of [[About Page]] (or directly by URL).
- Draft/archived projects are hidden ([[Content & CMS]]).
